# Blog CMS 使用指南

## 启动

首次运行：

```bash
cd cms
npm run install:all
```

之后在博客根目录执行：

```bash
npm run cms
```

浏览器打开 http://localhost:5173。

---

## 写文章

1. 点击侧边栏「文章」→「新建文章」。
2. 在顶部输入标题，正文区直接写作。
3. 使用编辑器工具栏插入标题、粗体、列表、代码、图片等。
4. 右侧填写摘要、标签、发布日期、封面图，或勾选置顶。
5. 点击「保存草稿」保存到磁盘；点击「发布」直接以已发布状态保存。
6. 输入过程中会自动保存到浏览器本地，不会产生多余文件；即使误关页面，下次新建时会提示恢复本地草稿。

### 编辑器

- 顶部左侧：格式工具栏
- 顶部右侧：编辑 / 分屏 / 预览切换、全屏写作
- 底部：字数、预估阅读时长
- `⌘/Ctrl + S` 保存，`⌘/Ctrl + B/I/K` 加粗/斜体/链接
- 直接拖拽或粘贴图片即可上传，图片会进入 `public/images/年/月/`

### 状态与日期

- 草稿状态的徽章可点击发布；已发布状态可点击转回草稿
- 编辑已有文章并保存后，会自动写入 `updatedDate`
- 发布日期使用本地时间，可在右侧修改或点「现在」

### 预览

- 「预览」：在 CMS 内查看接近博客正文的 Markdown 渲染效果
- 「在博客中打开」：跳转到本地 Astro 博客的对应文章（需要博客 dev server 运行在 4321）

### 重命名路径

编辑器右侧文件路径卡片中有「重命名」，可修改文章在 `src/content/post` 下的路径。路径会影响文章 URL。

## 笔记

1. 侧边栏「笔记」→「新建笔记」。
2. 填写标题、正文；发布设置中可选择日期。
3. 保存后会写入 `src/content/note/YYYY/MM/DD/index.md`。
4. 同样支持本地草稿、分屏预览、图片上传和「在博客中打开」。

---

## 标签

1. 侧边栏「标签」→「新建标签」。
2. 标签名称用于文件名和 URL，创建后不可修改；显示标题和描述可随时编辑。
3. 标签卡片上的「N 篇」可直接跳转到筛选后的文章列表。
4. 删除标签不会移除文章 frontmatter 中的标签文字，只会移除标签页文件。

---

## 资源

1. 侧边栏「资源」进入 `public` 目录。
2. 顶部「上传文件」或直接把文件拖到页面中。
3. 图片会显示缩略图，点击可放大预览。
4. 图片卡片上可：
   - 复制路径 ` /202511/photo.jpg`
   - 复制 Markdown `![photo](/202511/photo.jpg)`
   - 重命名
   - 删除
5. 可以新建文件夹、进入子目录上传，面包屑和返回按钮用于导航。

上传图片会自动去除 EXIF 元信息并压缩，重复文件名会自动追加 `-1`、`-2`，不会覆盖原文件。

---

## 仪表板

- 显示文章、草稿、笔记、标签数量
- 最近文章与草稿箱可快速进入编辑
- 左下角「打开博客」会显示本地博客开发服务器状态

## 常见问题

### 页面空白或 404

确认访问的是 http://localhost:5173，且前端 dev server 正常运行。

### 保存后文件在哪里

- 文章：`src/content/post/YYYY/MM/DD/`
- 笔记：`src/content/note/YYYY/MM/DD/`
- 标签：`src/content/tag/`
- 图片：`public/images/YYYY/MM/`（编辑器上传）或资源页当前目录

### 文章页打不开

CMS 的「在博客中打开」依赖 Astro dev server：

```bash
npm run dev
```

运行后博客地址为 http://localhost:4321。

### 端口冲突

- API 默认 3001，可用 `CMS_PORT=3002 npm start` 修改
- 前端固定 5173，请先释放该端口

### 恢复本地草稿

新文章未保存就关闭页面时，内容保存在浏览器 localStorage。再次新建文章会自动恢复，并提示「已恢复上次未保存的本地草稿」。
